Read this before acting on any of it

Beating a constant is not beating a price

These tests say three models pick games well. They say nothing about whether they beat a bookmaker, because the market picks games well too.

Card weights are set by the market tests, not these ones. WNBA is the only market with any positive signal against a price, and it is unproven, not proven — βmodel +0.35 (p = 0.29) with a lookahead injury feature, +0.07 (p = 0.87) without it. Nothing on this page justifies raising a weight.

What the tests turned up

Findings that changed the code

NFL · fixed

A margin scale calibrated for a model that wasn’t shipping

The scale is fitted out of sample by holding out the most recent training season. With a three-season list that leaves _fit_on holding 2023 alone — 286 games. So the scale was calibrated against ratings built from one season, then applied to a model built from three. Sharper ratings deserve a narrower scale and got the wide one.

16.14→12.40

The model was underconfident: 65% where it should have said 71% on a 10-point favourite. The fix is SEASONS, not the constant.

NFL · fixed

The Pro Bowl was in the training set

ESPN reports it as an ordinary final with AFC and NFC as franchises. Seven were being trained on, averaging 44.9 points a side against 23.0 for real games. Worse, it is played in February — so it was the most recent game in the set, taking the largest recency weight and anchoring the decay clock for every other row.

48.3→45.8implied total, vs 46.0 actual
WNBA · method

Two lookaheads that would have flattered the model

The shipped coefficients are wnba_fit_v2.json, trained on 1,246 games including 2026 — rounding in the source hides it, since 1.0992876 ships as 1.0993. And priors2025 seeds every team with 2025 ratings regardless of date: correct live, but the future in a 2022–24 replay.

Both removed. The good news underneath: an honest walk-forward refit lands in the same place, so the coefficients themselves are sound.

MLB · trap

A single split said the opposite

On one 521-game window an unregularised refit wanted a pythagorean coefficient of 5.92 against the shipped 0.33, and beat it — which reads exactly like a model 18× under-scaled.

It did not survive walk-forward, which reversed the ranking entirely. One window plus five collinear features is enough noise to produce a large, confident, wrong coefficient.

All sports

Home advantage alone never beats the base rate

In every sport with skill — CFB, NFL and WNBA — a model that knows only who is at home fails to beat the constant, with a confidence interval spanning zero each time. The signal lives entirely in the team ratings.

The same structural bug can also be fatal in one sport and immaterial in another. NFL’s starved scale fit cost it 30% of its confidence; the identical pattern in CFB is harmless, because a college season is 911 games to the NFL’s 286. Measure per sport — never port a fix on the strength of a shared code pattern.

Method

How these were run

Walk-forward. For each slate, the model is fitted on every game strictly before it, then predicts that slate. Nothing is ever scored on data it has seen. The MLB test showed why this matters: a single train/test split gave the opposite answer.

Paired bootstrap. Significance comes from 20,000 resamples of per-game log loss, paired against the baseline on the same games. Log loss rather than accuracy, because accuracy discards the confidence attached to each pick — and confidence is what a bet is made of.

The baseline is a moving constant — the home-win rate over prior games only, never the final season figure, which would itself be lookahead.
